# 常用方法速览

- 适用版本：SiYuan `v3.8.5` / `petal v1.2.8`
- 最后核对：2026-09-25
- 稳定性：stable
- 权威来源：
  - <https://github.com/siyuan-note/petal/blob/main/siyuan.d.ts>

## 1. 网络与通信

### `fetchSyncPost`

```ts
fetchSyncPost<T = any>(url: string, data?: any): Promise<IWebSocketData>
```

- **用途**：以 Promise 风格同步等待内核 API 响应，思源插件开发中最推荐的请求方式。在 `siyuan@1.2.8` 中已支持由内核 API 契约驱动的端到端强类型参数与返回推导。
- **返回模型**：
  ```ts
  interface IWebSocketData {
    code: number; // 0 代表成功，非 0 代表失败
    msg: string;  // 错误信息
    data: any;    // 负载数据
  }
  ```

### `fetchPost`

```ts
fetchPost(
  url: string,
  data?: any,
  cb?: (response: IWebSocketData) => void,
  headers?: IObject
): void
```

- **用途**：异步回调风格调用内核接口，支持传入自定义 HTTP Headers。

## 2. 交互与用户提示

### `openInputDialog` (v3.8.4+)

```ts
openInputDialog(options: {
  title: string;
  value: string;
  label?: string;
  placeholder?: string;
  multiline?: boolean; // 是否渲染为多行文本框 textarea
  maxLength?: number;
  width?: string; // 默认桌面端 520px，移动端 92vw
  description?: string; // 输入框下方的说明文本/HTML
  extraContent?: string; // 附加控件 HTML
  actions?: {
    text: string;
    position?: "beforeCancel" | "beforeConfirm" | "afterConfirm";
    danger?: boolean;
    onClick: (value: string, dialog: Dialog) => void;
  }[];
  onConfirm: (value: string, dialog: Dialog) => void;
}): Dialog
```

- **用途**：官方统一的单行/多行输入对话框，支持回车确认、ESC关闭、自定义扩展操作按钮与前置校验，替代以往手工使用 `new Dialog()` 拼接输入界面的做法。

### `showMessage` / `hideMessage`

```ts
showMessage(text: string, timeout?: number, type?: "info" | "error", id?: string): void
hideMessage(id?: string): void
```

- **用途**：在右上角弹出系统消息提示条。
- **参数**：
  - `timeout`：自动消失毫秒数（默认 6000，`0` 为常驻）。
  - `type`：`"info"`（默认提示）或 `"error"`（红色错误告警）。
  - `id`：指定唯一 ID，用于通过 `hideMessage(id)` 手动关闭。

### `confirm`

```ts
confirm(
  title: string,
  text: string,
  confirmCallback?: (dialog: Dialog) => void,
  cancelCallback?: (dialog: Dialog) => void
): void
```

- **用途**：弹出原生确认模态框，用于执行破坏性操作（如批量删除文档、清空数据）前的阻断式确认。

## 3. 页面、窗口与环境判断

### `openTab`

```ts
openTab(options: {
  app: App;
  doc?: { id: string; zoomIn?: boolean };
  custom?: {
    icon: string;
    title: string;
    data?: any;
    id: string; // 对应 addTab 声明的 type
  };
  position?: "right" | "bottom";
  openNewTab?: boolean;
}): ITab
```

- **用途**：在编辑器主工作区分屏或以新页签打开文档、自定义插件面板。

### `getFrontend` / `getBackend`

```ts
getFrontend(): "desktop" | "desktop-window" | "mobile" | "browser-desktop" | "browser-mobile"
getBackend(): "windows" | "linux" | "darwin" | "docker" | "android" | "ios"
```

- **用途**：动态判断当前前端运行环境与操作系统内核平台，进行多端适配与降级。

### `adaptHotkey`

```ts
adaptHotkey(hotkey: string): string
```

- **用途**：将快捷键字符串按当前操作系统（如 macOS 与 Windows 的 `Ctrl` / `⌘`）进行自动转换和显示适配。

## 4. 密钥与安全变量 (v3.8.3+)

### `getSecret`

```ts
getSecret(name: string): string
```

- **用途**：按名称读取思源「设置 → 密钥和变量」中安全密钥库的明文值。
- **安全说明**：仅在本地管理员权限下可用，适合安全读取用户配置的大模型 API Key、第三方集成 Token 等。找不到时返回空字符串。

### `getVariable`

```ts
getVariable(name: string): string
```

- **用途**：按名称读取变量库中的明文变量值，用于非敏感业务全局配置。找不到时返回空字符串。

## 5. 动态挂载方法 (v3.8.3+)

### `addToolbarItem` / `removeToolbarItem`

```ts
addToolbarItem(item: IMenuItem): void
removeToolbarItem(name: string): void
```

- **用途**：动态向编辑器工具栏注册快捷按钮，思源会自动持久化并允许用户在「设置 → 外观 → 工具栏」中调整排序与自定义快捷键。

### `addBreadcrumbButton` / `removeBreadcrumbButton`

```ts
addBreadcrumbButton(options: {
  id: string;
  icon: string;
  title: string;
  callback: (event: MouseEvent, protyle: IProtyle) => void;
}): string
### `addTopBar` (v3.8.4/v3.8.5+ 增强)

```ts
addTopBar(options: {
  id?: string;
  icon?: string;
  title: string;
  position?: "right" | "left";
  element?: HTMLElement; // 自定义 DOM 元素挂载（提供时忽略 icon 和 callback）
  contextMenu?: (menu: subMenu) => void; // 桌面端右键上下文菜单回调（自动处理分隔线）
  callback?: (event: MouseEvent) => void;
}): HTMLElement
```

- **用途**：在应用顶部工具栏添加插件图标或自定义元素。
- **新特性**：
  - `contextMenu`：直接传入右键菜单回调，无需手动给 DOM 绑定原生 `contextmenu` 事件，思源会自动将其与系统显隐控制项拼合并规范分隔线；
  - `element`：直接挂载自定义 DOM 节点，完全由插件控制样式与交互，并自动接入顶栏显隐与顺序编排系统。

## 6. 插件发布服务公开数据快照 (v3.8.4+)

### `loadPublishData`

```ts
loadPublishData(): Promise<Record<string, string | number | boolean | null>>
```

- **用途**：供发布服务（Publishing Service）页面读取已获管理员授权的公开数据快照。
- **重要约束**：未授权（403）或尚未生成（404）时返回对应拒绝码，**严禁回退读取 `this.loadData()` 私有存储**。

### `savePublishData`

```ts
savePublishData(data: Record<string, string | number | boolean | null>): Promise<void>
```

- **用途**：在管理员环境中全量保存/替换公开数据快照。
- **重要约束**：必须在可写环境下调用；仅支持提交 `plugin.json` 中已声明的标量字段（字符串、数值、布尔值或 null）。

## 7. 命令注册与快捷键增强 (v3.8.4+)

### `addCommand`

```ts
addCommand(command: {
  langKey?: string;
  langText?: string;
  hotkey?: string;
  hotkeys?: string[]; // 支持多个备选默认快捷键列表（优先于 hotkey）
  when?: (context: ICommandContext) => boolean; // 上下文可用性谓词（控制是否在命令面板中呈现）
  enabled?: (context: ICommandContext) => boolean; // 启用状态谓词
  execute?: (context: ICommandContext) => void | Promise<void>; // 统一异步执行上下文
  callback?: (context?: ICommandContext) => void;
  globalCallback?: (context?: ICommandContext) => void;
}): void
```

- **用途**：向思源命令面板和快捷键系统注册全局或上下文敏感的操作命令。

## 8. 生产级类型化请求封装示例

```ts
import { fetchSyncPost, showMessage } from "siyuan";

export class ApiError extends Error {
  constructor(public code: number, message: string, public endpoint: string) {
    super(`[SiYuan API Error ${code}] ${endpoint}: ${message}`);
    this.name = "ApiError";
  }
}

export async function requestKernelApi<T = any>(
  endpoint: string,
  payload: Record<string, unknown> = {}
): Promise<T> {
  const response = await fetchSyncPost(endpoint, payload);
  if (response.code !== 0) {
    showMessage(response.msg || `调用 ${endpoint} 失败`, 5000, "error");
    throw new ApiError(response.code, response.msg, endpoint);
  }
  return response.data as T;
}
```
