# 思源笔记插件“搜 easy”版本更新记录

## v1.3.0
### 新增
- **命中直达**：编辑搜索结果序号，直接跳转到对应命中结果位置；
- **提取命中块**：提取包含搜索关键词的块内容/块引用（默认为块内容，支持设置为块引用）批量复制到剪贴板，供后续处理；
- **支持移动端**：支持在手机等移动设备上使用搜索/替换基础功能；
- **插件联动**：支持 无界（siyuan-canvas）的画布上文本搜索与替换；
- **插件联动**：支持 思流 (siyuan-terminal，暂未上架) 终端文本的搜索；

### 优化
- 搜索性能优化；
- UI、图标、预览效果等细节优化，提升用户体验；

## v1.0.0
搜 easy 为思源笔记当前文档提供更接近 VS Code 的查找与替换体验。

### 首版本功能
- 在当前文档内逐个查找与替换
- 区分大小写、全词匹配、正则匹配
- 支持仅在当前选区内查找与替换
- 支持当前文档 minimap 与命中位置显示
